# Опис репозиторію KSE-Loc-Data-Hub

## Загальний огляд

Цей репозиторій є комплексним дата-хабом для дослідження реформи децентралізації в Україні (2014-2022 роки). Проект досліджує вплив реструктуризації місцевих рад (11 250 одиниць) у об'єднані територіальні громади (1 469 одиниць) та ефект цієї трансформації на ключові макроекономічні та соціальні показники. 

Особливий інтерес становить **стійкість громад до повномасштабного російського вторгнення, розпочатого 24 лютого 2022 року**.

## Структура репозиторію

### Основні директорії:

- **data/** - Централізоване сховище всіх наборів даних
  - `data/raw/` - Необроблені дані, зібрані з публічних джерел або отримані через офіційні запити
  - `data/derived/` - Очищені, агреговані дані, готові для аналізу

- **src/** - Всі скрипти проекту
  - `src/manipulation/` - Скрипти для перетворення сирих даних у оброблені набори
  - `src/analysis/` - Аналітичні скрипти для генерації графіків, таблиць і дашбордів
  - `src/utilities/` - Допоміжні функції та код загального призначення

- **maps/** - Просторові дані та візуалізації
  - Містить основний файл `full_dataset.csv` з повним набором даних
  - Картографічні матеріали для аналізу та звітності

- **workshop/** - Навчальні матеріали
  - Містить скрипт `workshop-maps.R` для створення карт з даними про ВПО (внутрішньо переміщених осіб)

- **reports/** - Звіти та публічні матеріали
- **assets/** - Логотипи, зображення та інші візуальні елементи

## Основні дані

Головний файл даних `maps/full_dataset.csv` містить:
- **22 995 записів** (рядків) - по одному для кожної громади
- **115 колонок** з різноманітними показниками
- Дані охоплюють географічні, адміністративні, демографічні, бюджетні, політичні та воєнні аспекти

## Дослідження та опитування

КШЕ провів два опитування громад у 2022 році для вивчення впливу повномасштабного вторгнення Росії:

1. **Перше опитування** (червень-серпень 2022): 477 громад
2. **Друге опитування** (жовтень-листопад 2022): 138 громад

## Мета проекту

Репозиторій має на меті:
- Надати структурований дата-хаб для майбутніх досліджень на субнаціональному рівні в Україні
- Підтримати прийняття політичних рішень на місцевому рівні
- Дослідити фактори стійкості громад до різних типів воєнних шоків
