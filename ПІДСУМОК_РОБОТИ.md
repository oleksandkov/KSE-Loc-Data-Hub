### 3. Детальний опис full_dataset.csv ✅

Створено вичерпний опис у файлі `ОПИС_КОЛОНОК_FULL_DATASET.md`, який включає:

#### Структура датасету:
- **1,469 записів** (рядків) - по одному для кожної громади України
- **115 колонок** з різноманітними показниками

#### Категорії даних:
1. **Адміністративна інформація** (11 колонок)
   - Коди та назви громад, районів, областей
   - Типи громад, адміністративні центри

2. **Географічні характеристики** (16 колонок)
   - Координати, площа, відстані до кордонів
   - Гірські громади, близькість до моря

3. **Воєнний стан та окупація** (5 колонок)
   - Статуси воєнних зон на різні дати 2022 року
   - Окупація до 2022 року

4. **Демографічні показники** (4 колонки)
   - Загальне та міське населення
   - Частка міського населення

5. **Бюджетна інформація** (30+ колонок)
   - Доходи 2021-2022 років
   - Трансферти, податки, власні доходи
   - Річні зміни показників

6. **Характеристики керівництва** (17 колонок)
   - Демографічні дані голів громад
   - Освіта, досвід роботи, партійність

7. **Громадські організації** (9 колонок)
   - ОСББ, молодіжні центри
   - Форми електронної демократії

8. **Медичні декларації** (15 колонок)
   - Розподіл за статтю, місцем проживання, віком

9. **Транспортна інфраструктура** (1 колонка)
   - Наявність залізничних станцій

## Рекомендації для подальшого використання

1. **Встановити необхідні пакети R**:
   ```r
   install.packages(c("tidyverse", "sf", "tmap", "readxl", "janitor", "stargazer", "scales"))
   ```

2. **Використовувати виправлену версію**:
   ```bash
   cd workshop
   Rscript workshop-maps-fixed.R
   ```

3. **Для валідації системи**:
   ```bash
   cd workshop  
   Rscript test-requirements.R
   ```
